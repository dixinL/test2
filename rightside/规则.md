# 个股右侧区间判定规则（rightside）

> 依据 2026-10-15 代码整理，2026-11-02 增补四态口径（新增震荡）：`conditions.py` / `rightside.py` / `indicators.py` / `db.py` / `run.py`。调参只改 `conditions.py` 顶部常量，本文档需同步。

## 一、定位

右侧行情 = **下跌趋势终结、底部反转得到验证之后的上涨阶段**——不是最低点，是拐点确认之后。震荡 = 下跌止住但反转未验证的横盘磨底段（左侧细分）。四态输出：`确认右侧 > 弱右侧 > 价格达标(环境缺失) > 震荡 / 左侧 > 排除`。仅技术分析思路，不构成投资建议。

**确认右侧 ≠ 买点**：本工具是趋势状态机（窗口 20~120 日），输出"参与资格"而非短线信号；确认后的回踩介入原则见第八节。

## 二、数据源与前置条件

| 数据 | 来源 | 说明 |
|---|---|---|
| 个股日线 | `general-data/leaders.db` 表 `daily` | 停牌行也在，close 为 None 的行剔除 |
| 复权因子 | 表 `adjust_factor` | 价格类指标**现算前复权**（原始价×因子），避免除权跳空制造假金叉/假破位 |
| 量能/涨跌/状态 | `daily` 原始字段 | `volume`、`pct_chg`（涨跌方向）、`is_st`、`tradestatus` 不复权 |
| 财务 | 表 `financial` | 业绩恶化旗标用（`yoy_ni`、`pub_date`） |
| 板块环境 | `general-data/env/env_YYYY-MM-DD.csv` | test1 `env_summary` 副本（envfetch.py 拉取）：宽度/拥挤度/场景/信号 |
| 板块趋势 | `general-data/env/trend_YYYY-MM-DD.csv` | test1 `sw_trend_summary` 副本，仅单股明细展示用 |
| 大盘 | 表 `index_daily`（sh.000001） | E3 用 |

**数据门槛**（`rightside.build_context`）：
- 有效日线 < `MIN_ROWS=130` 行 → 排除；
- 最新行 `trade_date != 判定日`（停牌/滞后）→ 排除。

**判定日**（`db.get_target_date`）：默认取近 5 个交易日中**覆盖股票数最多的共识日**——不能取全局 MAX（baostock 盘后陆续入库，当日可能只有少数股票）。可用 `--date` 覆盖。

## 三、条件组（编号与阈值）

### 门槛与旗标
| 编号 | 名称 | 规则 | 档位 |
|---|---|---|---|
| F1 | 非ST/停牌 | `is_st∈(0,None)` 且 `tradestatus∈(1,None)`；未过直接**排除** | gate |
| F1F | 业绩恶化 | 最近两个已披露报告期（pub_date≤判定日）`yoy_ni` 均为负 → ⚠ 提示，**不拦截** | flag |

### 弱档（WEAK：弱右侧的必要条件）
| 编号 | 名称 | 规则 | 阈值 |
|---|---|---|---|
| P1 | 不再创新低 | 近 20 日最低价 **>** 近 120 日最低价（上市不足 120 日 → ❓） | `NO_NEW_LOW_DAYS=20`，`LOW_WINDOW=120` |
| P2 | 箱体突破 | 近 **10** 日内存在突破日 b（收盘 > 其前 60 日最高价，不含 b），且 b 起收盘**从未收于**该上沿之下（站稳口径，不必当日突破）；取最近一个站稳突破日 | `BOX_WINDOW=60`，`BREAK_STAND_DAYS=10` |
| M1 | 20日线 | 收盘 > MA20 且 MA20 当日不下行（`ma20[i]≥ma20[i-1]`） | — |
| M2 | MACD金叉 | 近 **30** 日内出现 DIF 上穿 DEA（**不限 0 轴位置**） | `MACD_CROSS_DAYS=30` |
| V1 | 放量突破 | 附着于 P2 的站稳突破日 b：b 日量 / 其前箱体期(60日)均量 ≥ 1.5；近 10 日无站稳突破 ❌ | `VOL_BREAK_RATIO=1.5` |
| E1 | 板块宽度 | env `width` ≥ 30 | `E1_WIDTH_MIN=30` |
| E2 | 板块拥挤度 | env `congestion` < 80 | `E2_CONG_MAX=80` |

### 震荡形态（SHAPE：左侧细分，不参与右侧门槛）
| 编号 | 名称 | 规则 | 阈值 |
|---|---|---|---|
| X1 | MA20走平 | MA20 近 N 日变化率绝对值 < 阈值 | `X_FLAT_DAYS=5`，`X_FLAT_PCT=1%` |
| X2 | 贴线震荡 | 近 N 日收盘相对 MA20 平均绝对偏离 ≤ 阈值 | `X_DEV_DAYS=10`，`X_DEV_MAX=3%` |
| X3 | 区间收敛 | 近 N 日最高/最低振幅 ≤ 阈值 | `X_AMP_DAYS=20`，`X_AMP_MAX=15%` |

数据不足一律 ❓；X 条件只在弱档价格条件（P1/P2/M1/M2/V1）未过时参与震荡判定。

### 强档（STRONG：确认右侧的全部条件）
| 编号 | 名称 | 规则 | 阈值 |
|---|---|---|---|
| P1S | 低点抬升 | 近 20 日摆动低点（左右各 2 位严格更低）≥ 2 个且**逐级抬升** | `SWING_LOW_DAYS=20` |
| P2S | 回踩不破 | 近 20 日内存在突破日 b（收盘>其前 60 日上沿），突破后至当日低点不破该上沿，且当日收盘 ≥ 上沿 | `PULLBACK_DAYS=20` |
| M1S | 60日线三态 | 近 30 日 MA60 状态序列出现 **下→走平→向上**，且收盘连续 ≥5 日站上 MA60 | `MA60_ABOVE_DAYS=5`，三态阈值 ±0.2%/5日 |
| M2S | MACD 0轴上 | DIF > 0 | — |
| V1S | 量价健康 | 近 20 日**上涨日均量/下跌日均量** ≥ 1.2（涨跌用原始 `pct_chg`，除权日口径正确） | `VOL_HEALTHY_RATIO=1.2` |
| R1 | RSI≥50 | RSI14 ≥ 50（Wilder 平滑） | — |
| E1S | 板块场景确认 | env 场景 ∈ {S2, S4, S8}（积极场景）或信号 = ★ | `E1_CONFIRM_SCENES` |
| E3 | 大盘MA20 | 上证综指收盘 > MA20 | — |

**数据不足一律 ❓（None）**，不臆判。

## 四、四态判定（`rightside.classify`，优先级从上到下）

1. F1 未过 → **排除**
2. 任一弱档**价格**条件（P1/P2/M1/M2/V1）为 ❌ → **震荡 / 左侧**：X1~X3 全 ✅ 且 P1 非 ❌（未创新低）→ **震荡**（横盘磨底）；否则 **左侧**（阴跌/破位）
3. E1/E2 任一为 ❌ → **左侧**（环境明确否决，不产生震荡）
4. E1/E2 任一为 ❓（环境快照缺失）→ **价格达标(环境缺失)**（价格面已全过，仅环境无法验证）
5. 全部强档（P1S/P2S/M1S/M2S/V1S/R1/E1S/E3）为 ✅ → **确认右侧**
6. 其余 → **弱右侧**（弱档全过、强档未全过）

## 五、指标口径（`indicators.py`，标准库实现）

- **SMA**：简单移动平均；**EMA**：首值种子递推，alpha=2/(n+1)（通达信/东财口径）；
- **MACD(12,26,9)**：DIF=EMA12−EMA26，DEA=EMA9(DIF)，hist=2×(DIF−DEA)；
- **RSI14**：Wilder 平滑；
- **摆动低点**：`low[i]` 严格低于左右各 2 位；
- **MA60 单日三态**：5 日斜率变化 >+0.2% 向上 / <−0.2% 向下 / 其余走平。

## 六、环境快照降级（`db.load_env` / `name_map.py`）

- 取判定日（含）之前最新一份 `env_*.csv`；`env_date != 判定日` 时明细标注 `(数据截至 X)`；
- `leaders.sw2` → env `sw_name` 有对不上的，走 `name_map.NAME_FIX` 人工修正映射；仍对不上 → `(行业名对不上: X)`，报告尾部集中列出提醒补映射；
- 无任何快照 → E1/E1S/E2 全 ❓，四态按第 4 条降级为「价格达标(环境缺失)」。

## 七、用法与输出

```bash
python run.py                        # 全量龙头，默认共识判定日
python run.py --date 2026-10-09      # 指定判定日
python run.py --code 600519          # 单股明细（逐条 ✅/❌/❓ + 明细值 + 板块趋势行）
```

输出 `rightside/report/rightside_{date}.md`：市场环境（test1 结论）→ 按 确认右侧/弱右侧/价格达标(环境缺失)/震荡/左侧/排除 分组表格（代码|名称|申万二级|状态起点|辅助信号|关键说明）→ 行业名映射提醒。关键说明 = 未过关键条件摘要（弱右侧看强档、左侧/震荡看弱档，最多 3 条）+ 业绩恶化旗标；辅助信号仅确认/弱右侧计算（见第十节）。

**状态起点（基础数据现算，`rightside.state_start_real()`）**：
- 仅对**弱右侧/确认右侧/价格达标(环境缺失)/震荡**显示（`MM-DD 起（N天）`）；左侧是兜底态（弱档任一 ❌ 即左），连续段无信息量，起点显示 `-`；震荡段反映磨底时长，同样显示起点；
- 现算口径与状态列一致：在该股完整日线上逐日重判（P1/P2/M1/M2/V1 任一 ❌ → 震荡/左侧，区分同第四节；E1/E2 明确 ❌ → 左侧；价格全过 + 强档全过 → 确认右侧；其余 → 弱右侧），取当前连续段起点；
- 环境快照缺失的历史日 E1/E2/E1S 为 ❓，视为"环境不否决"（不断开连续性）；环境明确 ❌ 时正常断开。注意：环境快照存在时以**报告所用当日快照值回溯全部历史日**（历史环境序列不可得，属近似；未来 env 快照积累后可改为逐日环境）；
- 「价格达标(环境缺失)」与「弱右侧」在连续性上视为同一状态；状态翻转即重新起算；
- 回溯到可评估序列开头（P1 需 120 行）仍未翻转时显示 `早于 YYYY-MM-DD`（完整日期，可能跨多年），表示真实起点更早。

**状态观察记录**（`states.py` → `report/rightside_states.csv`，列 date,code,name,sw2,state）：
- 每次全量运行按判定日幂等重写当日行，重复运行无副作用；CSV 随 report/ 进 git 跨日累积；
- 定位是**每日观察记录**（CI 全量重建 leaders.db 时靠 git 里的它跨日累积），供总览统计当日分组；不用于回溯起点；
- 历史回填（`--date`）当日无环境快照时按降级口径判定，与常规运行一致。

## 八、确认后的回踩介入逻辑（使用原则，非自动信号）

**为什么不按确认日买**：全部条件确认完时，价格通常已离底部 20%~30%；且 V1 要求突破日 ≥1.5 倍量，确认日往往恰是箱体上沿的情绪偏热位置。按确认日买入 = 追高。左侧终结→右侧确认对短线意义不大，追求的应是**中长期波动**：确认 = 拿到候选池资格，介入 = 等回踩。

**四态的使用定位**：
- 震荡：筑底跟踪池——下跌已止、反转未验，观察量价结构酝酿，不介入；升级到弱右侧再观察；
- 弱右侧：观察池——结构初成、反复多，不介入或极小仓位试错；
- 确认右侧：中长期波段候选池——**等回踩介入**；
- 短线择时（当日触发/分时确认）不在本工具范围，另行处理。

**介入参照**（由既有条件推导）：
1. **标准介入形态 = P2S 的结构**：突破 60 日箱体上沿 → 回踩至上沿附近（前阻力转支撑）不破 → 再起。P2S 首次转为 ✅ 的确认日说明"回踩已验证过一次"，是入池时点；
2. **介入位置看乖离**：确认后价格贴近箱体上沿（`top_b`）或 MA20 附近时介入优于远离上沿时追入；乖离过大则等下一次回踩；
3. **环境过滤**：回踩介入时 E1S（板块积极场景/★）与 E3（大盘>MA20）仍成立，胜率更高——环境转差宁可放弃本次回踩；
4. **介入失效（止损参照）**：收盘跌回箱体上沿之下 → 本次突破/回踩逻辑失效；进一步跌破 MA60 且 MA60 转下 → 右侧结构破坏（三态随之降回弱右侧/左侧），趋势前提不再成立。

> 注：以上为使用原则，工具目前不输出乖离/回踩触发信号；如需规则化，需新增"确认后乖离率 / 回踩触发"字段（后续迭代项）。

## 十、辅助信号层（仅展示，不参与三态判定）

**定位**：退场时机研究的观察性指标。只对**确认右侧/弱右侧**（观察池/候选池）计算展示，
不改第四节三态判定，不进 states.csv。输出在 rightside 报告「辅助信号」列与总览明细表，
多项并存用 `·` 连接，无信号显示 `-`/`—`。

| 信号 | 口径（`rightside.aux_warnings`，常量在 rightside.py 顶部） | 含义 |
|---|---|---|
| MACD死叉 | 近 `AUX_DEAD_CROSS_DAYS=5` 日 DIF 下穿 DEA | 趋势动能转弱预警 |
| OBV背离 | 近 `AUX_OBV_WINDOW=60` 日收盘创新高而 OBV 未同步创新高 | 价升量未跟，上攻乏力（`indicators.obv`） |
| 涨时缩量 | 近 `AUX_VOL_WINDOW=10` 日 上涨日均量 < 下跌日均量 | 与 V1S 同口径，缩窗缩阈值作短线预警 |
| 板块弱 | 行业宽度 < `AUX_WIDTH_SOFT_MIN=40`（env 快照，缺失时静默跳过） | 宽度=行业内 MA20 上方个股占比；在 E1 硬门槛 30 之上预警板块结构单薄 |
| 大盘弱 | 市场宽度状态 ∈ `AUX_MARKET_WEAK_STATES={弱,极弱}`（env 快照 MARKET 行） | 大盘结构性偏弱（价格在 MA20 上方也可能磨底结构弱，与 E3 互补） |
| 融资退潮 | 近 `AUX_MARGIN_DROP_DAYS=5` 日融资余额变化率 ≤ `AUX_MARGIN_DROP=-1%`（leaders.db margin 表，沪深合计，数据 <6 日静默跳过） | 杠杆资金退潮预警；报告/总览市场环境节附温度计行 `融资余额 N 亿（5日 ±x.x%）`（`rightside.fmt_margin`） |

两融数据基础设施（第 3 步，2026-10-30 建）：`general-data/marginfetch.py`（akshare 沪深两所官方汇总，
SSE 单位元、SZSE 单位亿元已归一；深市单日请求失败跳过待补齐；akshare 未安装/区间无新数据优雅跳过）→
